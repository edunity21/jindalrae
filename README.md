# 진달래꽃 × 서양음악사

김소월의 「진달래꽃」을 서양음악사 스무 개 시대·장르로 편곡한 음원을 듣고 비교하는 음악 감상 학습 페이지입니다. 중학교 음악과 수업과 학생 자기주도 학습에 쓰도록 만들었습니다.

가사는 고정하고 음악 양식만 바꾸었기 때문에, 학생이 "무엇이 달라졌는가"를 오직 음악 요소로만 설명하게 됩니다.

---

## 무엇이 들어 있나

첫 화면에서 **학습자용 / 수업자용** 중 하나를 고릅니다. 고른 쪽에 따라 완전히 다른 화면이 열립니다.

### 학습자용 (학번 · 이름 · 비밀번호로 접속)

| 탭 | 하는 일 |
|---|---|
| **시대 탐구** | 오선 위 스무 개 음표를 누르면 그 시대가 재생됩니다. 가로축은 시대 순, 세로축은 성부·음향 층의 두께입니다. |
| **듣고 맞히기** | 제목을 가린 채 무작위 재생 → 4지선다. 정답 후 판별 단서와 해설이 나옵니다. |
| **순서 세우기** | 여섯 곡을 무작위로 뽑아 시대 순으로 배열하고 자리별로 채점합니다. |
| **감상 활동지** | 빠르기·셈여림·음색·짜임새·느낌 5개 항목 + 서술 2문항. 저장·내려받기·엑셀·메일·인쇄·제출 파일 만들기. |

### 수업자용 (비밀번호로 접속)

| 탭 | 하는 일 |
|---|---|
| **수업 진행** | 교실 큰 화면용. 곡 제목·시대·특징이 큰 글씨로 나오고 이전/재생/다음 버튼이 큽니다. **제목 가리기**로 블라인드 감상을, **노랫말**로 시를 띄울 수 있습니다. 좌우 화살표 키로도 넘깁니다. |
| **학생 기록** | 학생별 / 곡별 / 응답 통계 세 가지로 보고, 엑셀·CSV로 내려받습니다. 학생 제출 파일을 불러와 합칠 수 있습니다. |
| **수업 운영** | 45분 차시 운영안, 학습목표, 핵심 발문. 이 탭만 인쇄하면 지도안이 됩니다. |
| **시대 탐구** | 학습자용과 같은 자료 화면입니다. |

### 비밀번호

`assets/js/data.js` 맨 위 `CONFIG`에서 바꿉니다.

```js
var CONFIG = {
  studentPw:    "sp2026",   // 학습자용
  adminPw:      "po8286",   // 수업자용
  teacherEmail: "",         // 학생이 [메일 보내기]를 눌렀을 때 받을 주소
  schoolName:   "승평중학교",
  subject:      "음악"
};
```

> ⚠️ **비밀번호는 보안장치가 아닙니다.** GitHub Pages는 서버가 없는 정적 호스팅이라 비밀번호가 페이지 소스에 그대로 들어갑니다. 브라우저에서 소스를 열면 누구나 볼 수 있습니다. 수업용 출입문 정도로만 여기시고, 민감한 정보는 절대 넣지 마세요.

## 학생 기록이 선생님에게 오는 방법

여기가 가장 중요합니다. **서버가 없으므로 기록은 각자 기기의 브라우저에 저장됩니다.** 선생님 기기가 학생 기기의 기록을 자동으로 가져올 수는 없습니다. 상황에 따라 두 가지 길이 있습니다.

### 컴퓨터실처럼 한 기기를 여러 학생이 쓰는 경우 — 자동으로 모입니다

학생이 차례로 로그인해 작성하면 그 기기에 학번별로 쌓입니다. 수업이 끝난 뒤 그 컴퓨터에서 **수업자용으로 로그인 → [학생 기록] → [총괄 엑셀]** 을 누르면 그 기기에서 작성된 전원의 기록이 한 파일로 나옵니다.

### 학생이 각자 휴대폰·태블릿으로 하는 경우 — 제출받아 합칩니다

1. 학생: 활동지 작성 후 **[선생님께 제출 파일 만들기]** → `제출_3105_홍길동_260815.json` 파일이 만들어집니다
2. 학생: 그 파일을 이메일·구글클래스룸·패들렛 등으로 제출
3. 선생님: **[학생 기록] → [제출 파일 불러오기]** 에서 받은 파일들을 **한꺼번에 선택**하면 전원이 합쳐집니다
4. 이후 엑셀로 내려받습니다

메일 제출도 됩니다. 학생이 **[메일 보내기]** 를 누르면 기본 메일 앱이 열리고 내용이 본문에 채워집니다. 다만 스무 곡 전체는 본문이 길어 일부 메일 앱에서 잘릴 수 있으니, 전체 제출은 **제출 파일**이나 **엑셀 첨부**를 권합니다.

### 내려받기 종류

| 누구 | 버튼 | 결과 |
|---|---|---|
| 학생 | 이 곡만 → 내려받기 / 엑셀 / 메일 | 지금 보고 있는 한 곡만 |
| 학생 | 전체 → 내려받기 / 엑셀 / 메일 / 인쇄 | 작성한 스무 곡 묶음 |
| 학생 | 선생님께 제출 파일 만들기 | 선생님이 불러올 수 있는 `.json` |
| 선생님 | 총괄 엑셀 | **총괄 / 학생별 요약 / 응답 통계** 세 시트 |
| 선생님 | 곡별 엑셀 | 곡마다 시트를 따로 만든 파일 |
| 선생님 | 지금 보는 곡만 엑셀 | 한 곡에 대한 전원 응답 |
| 선생님 | CSV · 전체 백업 | 다른 프로그램에 넣거나 보관용 |

엑셀 파일은 외부 라이브러리 없이 페이지 안에서 직접 만들어집니다. 인터넷이 끊긴 교실에서도 동작합니다.

## GitHub Pages에 올리기

음원 전체가 37MB입니다. GitHub 웹 업로더는 한 번에 올리는 총량이 크면 **"커밋 실패 — 파일이 너무 커서 업로드할 수 없습니다"** 가 뜹니다. 아래 세 방법 중 하나를 쓰세요.

### 방법 A — GitHub Desktop (가장 확실, 권장)

용량 제한 문제가 아예 없고 명령어도 필요 없습니다.

1. [desktop.github.com](https://desktop.github.com) 에서 설치 후 GitHub 계정으로 로그인
2. **File ▸ New repository** → Name에 저장소 이름 입력 → Local path 지정 → **Create repository**
3. 만들어진 폴더를 열어(Repository ▸ Show in Explorer) 이 ZIP의 **내용물 전체**를 그 안에 복사
4. GitHub Desktop으로 돌아오면 변경 파일 목록이 뜹니다 → 아래 Summary 칸에 아무 문구나 입력 → **Commit to main**
5. 오른쪽 위 **Publish repository** → **Keep this code private 체크 해제** → Publish
6. 저장소의 **Settings ▸ Pages** → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → **Save**

### 방법 B — 웹에서 나눠 올리기

웹 화면만 쓰고 싶다면 **음원을 5개씩 나눠서** 올립니다.

1. 저장소 화면 → **Add file ▸ Upload files**
2. 먼저 **음원을 뺀 나머지만** 올립니다 — `index.html`, `README.md`, `.nojekyll`, `assets` 폴더 → Commit
3. **Add file ▸ Create new file** → 파일명 칸에 `audio/.gitkeep` 입력 (슬래시를 치면 폴더가 만들어집니다) → Commit
4. 저장소에서 방금 생긴 **`audio` 폴더를 클릭해 들어간 뒤** → **Add file ▸ Upload files**
   → 이제 업로드가 `audio` 폴더 안으로 들어갑니다
5. mp3를 **5개씩** 끌어다 놓고 Commit → 4번 반복 (01~05, 06~10, 11~15, 16~20)
6. **Settings ▸ Pages** → Branch: `main` / `/ (root)` → Save

⚠️ 4번을 건너뛰고 저장소 최상단에서 mp3를 올리면 `audio` 폴더 밖에 저장되어 재생되지 않습니다. 반드시 폴더 안으로 들어간 뒤 올리세요.

### 방법 C — 명령어

```bash
cd 이폴더
git init
git add .
git commit -m "진달래꽃 서양음악사 감상 페이지"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

이후 **Settings ▸ Pages**에서 위와 같이 설정합니다.

## 올릴 때 주의할 점

- **Git LFS를 쓰지 마세요.** LFS로 올린 파일은 GitHub Pages에서 재생되지 않고 텍스트 포인터만 내려옵니다. mp3는 일반 파일로 커밋하세요.
- **음원 파일 이름을 바꾸지 마세요.** 한글·공백이 든 이름은 일부 브라우저에서 주소 인코딩 문제로 재생이 실패합니다. 그래서 `01-primitive.mp3` 처럼 영문으로 바꿔 두었습니다.
- **`index.html`이 저장소 최상단**에 있어야 합니다. 폴더째 감싸지 마세요.
- 저장소는 **Public**이어야 무료 계정에서 Pages가 켜집니다.
- 웹 업로더 한도: 파일 1개당 25MB. 이 패키지의 가장 큰 파일은 2.5MB라 개별 파일은 문제없고, 문제는 **한 번에 올리는 총량**입니다.
- 첫 접속 때 음원을 내려받으므로 학교 와이파이가 느리면 수업 전에 한 번 열어 두세요.

### 음원 처리 내역

원본(320kbps, 75MB)에 두 가지 처리를 했습니다. 길이는 20곡 모두 원본과 동일합니다.

**1. 체감 음량을 고르게 맞춤**

곡을 넘길 때마다 볼륨을 조절하지 않아도 되도록 맞췄습니다. 판단 기준은 평균값(LUFS)이 아니라 **실제로 크게 들리는 대목의 음량**입니다. 평균만 맞추면 수치상으로는 같아도 귀로는 여전히 다르게 들리기 때문입니다.

| | 원본 | 최종 |
|---|---|---|
| 체감 음량 편차 | 10.8 LU | **0.1 LU** |
| 여린 대목 편차 | 17.0 LU | 11.8 LU |
| 피크가 0을 넘어 찌그러진 곡 | 3곡 | **0곡** |

20곡 전부 체감 음량 −15.5 LUFS로 맞았습니다. 다이내믹 폭이 특히 넓던 마드리갈·칸타타·오르가눔 등 12곡은 여린 대목이 묻히지 않도록 폭을 9 LU로 정돈했고, 원래 고르던 8곡(원시음악·힙합·K-pop 등)은 손대지 않았습니다.

원본에서 피크가 0을 넘어 이미 찌그러져 있던 원시음악·전자음악·R&B 세 곡도 함께 해결됐습니다.

**2. 용량 절반으로 축소**

평균 138kbps로 재인코딩해 75MB → 37MB가 됐습니다. 교실 스피커·이어폰 재생에서는 원본과 차이를 구분하기 어렵고, 업로드와 학생 기기 로딩 부담이 크게 줄어듭니다. 원본 음질이 필요하면 처음 만드신 파일을 그대로 쓰시면 됩니다.

**3. 화면 안에서 음량 조절**

그래도 교실 스피커 사정은 제각각이라 플레이어에 음량 조절을 넣었습니다. **− / ＋ 버튼, 슬라이더, 음소거** 세 가지로 조절되고, 설정한 음량은 기기에 기억됩니다. 키보드 **↑ ↓** 로도 조절됩니다.

## 내용 고치기

설명 문구, 특징, 감상 포인트, 발문, 수업안은 모두 **`assets/js/data.js`** 한 파일에 있습니다. 이 파일만 열어 텍스트를 바꾸면 페이지에 그대로 반영됩니다.

### 곡을 바꾸거나 추가하려면

1. 새 mp3를 `audio/` 에 영문 이름으로 넣습니다. 예: `21-minimalism.mp3`
2. `data.js`의 `TRACKS` 배열에 항목을 추가합니다.

```js
{
  n: 21,                          // 표시 번호
  slug: "21-minimalism",          // 확장자 뺀 파일 이름 (반드시 일치)
  era: "modern",                  // ERAS의 id 중 하나
  layers: 3,                      // 1~5, 오선 위 높이 = 성부·음향 층의 두께
  title: "미니멀리즘",
  sub: "Minimalism",
  years: "1960년대~",
  one: "한 줄 요약",
  bg: "시대 배경 문단",
  traits: ["특징1", "특징2", "특징3", "특징4"],
  listen: ["감상 포인트1", "감상 포인트2", "감상 포인트3"],
  words: ["용어1", "용어2"],
  who: "대표 작곡가 · 작품",
  lyric: "가사를 다루는 방식",
  clue: "퀴즈 정답 해설에 나오는 판별 단서"
}
```

`TRACKS` 배열의 **순서가 곧 시대 순서**입니다. 순서 세우기 채점도 이 순서를 기준으로 합니다. 중간에 끼워 넣을 때는 위치를 맞춰 넣고 `n` 값을 다시 매기세요.

## 저작권

- 시 「진달래꽃」: 김소월(1902~1934). 1922년 「개벽」 발표, 1925년 시집 『진달래꽃』 수록. 저작권 보호기간이 만료된 공유 저작물입니다.
- 음원: 수업 활용을 위해 시대 양식별로 새로 편곡·제작한 것으로, 실제 시대의 원곡 녹음이 아닙니다. 각 시대의 특징을 뚜렷이 드러내려 양식을 강조했으므로, 사료와의 차이는 수업에서 함께 짚어 주는 편이 좋습니다.
- 저장소를 공개할 때는 음원 제작 경위를 README에 밝혀 두시길 권합니다.
